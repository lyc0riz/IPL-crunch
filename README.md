# IPL Analysis (2008-2026)

This is a data driven analysis of IPL seasons.

## Dataset Used
I've used a ball by ball dataset for the analysis which I created myself by converting the JSON files from cricksheet.org to a structured CSV.

[Original Source](https://cricsheet.org/downloads/)
[Kaggle Dataset](https://www.kaggle.com/datasets/lyc0riz/ipl-ball-by-ball-dataset-2008-2026/data)

All credit for original data collection and raw files goes to Cricsheet. This dataset is made available on the website under the [Open Data Commons Attribution License](http://opendatacommons.org/licenses/by/1.0/).
